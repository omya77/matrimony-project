# ForeverBond - Full Stack Matrimony Platform 💍

Welcome to the **ForeverBond Matrimony** repository! 
This project is a comprehensive, feature-rich matchmaking platform built from scratch to demonstrate advanced backend architecture, real-time communications, and secure data handling.

🔗 **Live Website:** [Click Here to View ForeverBond Live](https://matrimony-project-bahb.onrender.com)

---

## 🛠️ Tech Stack & Architecture

* **Backend Framework:** Django, Python
* **Real-time Communication:** Django Channels, Daphne (ASGI), Redis (WebSockets)
* **Database Management:** SQLite (Render Ephemeral) / PostgreSQL (Production Concept)
* **Frontend UI:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Authentication:** Custom JWT / Session-based Auth with OTP bypass for testing.
* **Media Storage:** Cloudinary integration for scalable profile photo management.

## ✨ Key Features:

1. **Smart Matchmaking Algorithm:** Complex filtering based on religion, caste, age, and professional preferences.
2. **Real-Time Live Chat:** Fully functional one-to-one WebSocket chat for connected users.
3. **Automated Seed Data:** Over 100+ dummy profiles auto-generated for portfolio showcase purposes.
4. **Secure Payments:** Razorpay integration mockups for Premium and Elite membership plans.
5. **Admin Dashboard:** Customized Jazzmin admin panel to manage users, approve photos, and track transactions.
6. **Privacy Controls:** Image blurring for non-premium members to ensure data security.
